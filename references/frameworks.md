# 可填写工作表

## 第1步
选一个具体可表现的技能及安全边界，写完成时应出现的动作、作品或判断，不把会背概念当目标。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第2步
登记过去学习时间在阅读、观察、实际操作、反馈与反思的分配，查缺练习还是缺必要知识。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第3步
设计短而明确的练习，先给示范与成功标准，针对薄弱动作重复，避免只刷时长。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第4步
用安全环境记录本人实际完成情况及帮助程度，失败指到动作或知识缺口，不以天赋懒惰标签解释。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第5步
让学习者在少提示、新条件下再做，区分熟练重复与理解迁移；必要时补理论再练。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第6步
输出能力证据、未达项与下次训练分配，安排休息和反馈；验收通过仅对给定任务条件有效。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 证据和行动校验
关键条目至少填写一个来源定位（source）或下一步核验（next_check）。不将表格通过当作论证真实。可以用 `python scripts/validate_packet.py packet.json` 检查结构，工具不访问网络、不评判观点或代替专业审查。

## 确定性辅助工具

按技能目标记录独立表现与变条件证据；时长和提示完成不能自动成为能力认证。

输入例子见 [tool-input.json](../examples/tool-input.json)。
```sh
python scripts/check_practice.py examples/tool-input.json
```
工具只读取指定本地 JSON，不联网、不更改文件、不执行输入中的指令。填写者仍须复核事实和适用条件。
